Antes de firmar, usted revisa cada documento y, si el sobre lo requiere, confirma su identidad con
un código que llega a su correo. El indicador en la parte superior muestra en qué paso está:
**Revisar**, **Verificar** (cuando aplica) y **Firmar**.

## Confirmar sus datos

La pantalla muestra **Firmando como** con su nombre y su correo. Son los datos que aparecerán en el
sello del documento. Si no corresponden a usted, no continúe y comuníquese con quien le envió el
documento para que los corrija.

## Revisar cada documento

En **Documentos para revisar**, pulse **Ver** para abrir cada PDF en la misma página y **Ocultar**
para cerrarlo. Cuando haya abierto todos los documentos, pulse **He revisado el documento**. Si
intenta continuar antes, verá el mensaje "Abre cada documento antes de continuar."

Si su navegador no puede mostrar el PDF, verá "Tu navegador no puede mostrar este PDF
incrustado." Use **Descargar el documento** para abrirlo; esa descarga también cuenta como
revisión.

## Verificar su identidad

Cuando el sobre requiere verificación, al pulsar **He revisado el documento** bb-sign le envía un
código por correo y abre la pantalla **Verifica tu identidad**, que muestra el tiempo restante de
validez del código.

- El código tiene <Fact of={OTP.digits} unit="dígitos" /> y es válido durante <Fact of={OTP.validityMinutes} unit="minutos" />.
- Cada código admite <Fact of={OTP.maxAttempts} unit="intentos" />.
- Puede solicitar otro con **Reenviar código** <Fact of={OTP.resendCooldownSeconds} unit="s" />
  después del último envío; mientras tanto, el botón muestra la cuenta regresiva.
- La página acepta siempre el código más reciente.

Escriba el código y pulse **Verificar y continuar**.

## Mensajes de verificación

| Mensaje | Qué pasó | Qué hacer |
|---|---|---|
| "Ya te enviamos un código a tu correo." | Solicitó otro código antes de terminar la espera, y el anterior sigue vigente. | Use el código que ya recibió. |
| "Te hemos enviado un código nuevo." | Se envió un código nuevo. | Use el código nuevo. |
| "Ese código ya no se puede usar. Podrás pedir uno nuevo en unos instantes." | El código ya se usó o agotó sus intentos, y la espera sigue en curso. | Cuando el botón muestre **Reenviar código**, solicite otro. |
| "Ese código no es válido. Revísalo e inténtalo de nuevo." | El código no coincide, venció o no es el más reciente. Cada error cuenta como un intento. | Copie el código del último correo. Si agotó los intentos, solicite uno nuevo. |
| "No se pudo verificar el código. Inténtalo de nuevo." | La verificación no se completó. | Pulse de nuevo **Verificar y continuar**. |
| "No se pudo enviar el código OTP. Inténtalo de nuevo." | El correo no se pudo enviar. | Pulse de nuevo **He revisado el documento**. |

## Después de verificar

Una vez verificado el código, tiene <Fact of={OTP.verifiedValidityMinutes} unit="minutos" /> para
firmar. Si ese tiempo se cumple, recargue la página, abra de nuevo los documentos y solicite un
código nuevo. Continúe en [Firmar y descargar](/sign/signing/sign-and-download/).
