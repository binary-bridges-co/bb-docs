This table gathers every limit, period and default that appears in the bb-sign documentation. The
values come from the fact sheet that feeds every page, so what you see here is what you see on the
rest of the site. The third column names the file and line in bb-sign or its infrastructure where the
value was read. The last two rows are service policy, not infrastructure behaviour; the difference is
explained in [Scope and retention](/en/sign/legal/retention/).
