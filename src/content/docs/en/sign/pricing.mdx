bb-sign is charged per envelope. The price depends on how long your organization's files are kept.
Prices are in Colombian pesos (COP) per envelope and exclude VAT (IVA).

| Configuration | Price per envelope |
| --- | --- |
| **Standard configuration.** Each file is kept <Fact of={ORG_STORAGE.defaultRetentionDays} unit="days" />. | <Price of={PRICING.standardPerEnvelopeCop} /> |
| **<Fact of={ORG_STORAGE.maxRetentionYears} unit="years" /> retention.** Binary Bridges manages the storage tiers. | <Price of={PRICING.tenYearPerEnvelopeCop} /> |
| **More than <Fact of={PRICING.volumeThresholdEnvelopesPerMonth} /> envelopes a month.** | Volume discounts, down to <Price of={PRICING.volumeFloorPerEnvelopeCop} />. Write to us for a quote. |
| **Other configurations.** | Write to us for a quote. |

## What is charged

Every envelope created counts, drafts and cancelled envelopes included, just as the
[quota](/en/sign/concepts/quotas/) counts them.
