Labels let you classify envelopes and find them later by contractor, project or department. Each
label is a **key: value** pair. An administrator defines the keys for the whole organization and
whoever works with the envelope assigns the value. That way, the whole organization classifies with
the same categories.

## Keys and values

A **key** is a category with a name, a color and a description, for example `contractor`, `project`
or `department`. A **value** is what one specific envelope has in that category, for example
`Acme Inc.`, `Renewal 2026` or `Purchasing`. Each envelope takes one value per key, for the keys
defined in the organization. The envelope list shows each row's labels and lets you filter by them.

## Define the keys

On the **Label Keys** page (**Labels** in the menu), an Org Admin presses **New Key** and fills in:

| Field | Rule |
| --- | --- |
| **Name** | Required, unique in the organization, up to <Fact of={LABELS.keyNameMaxChars} /> characters. |
| **Color** | Tells the label apart in lists. |
| **Description** | Optional, up to <Fact of={LABELS.keyDescriptionMaxChars} /> characters. Use it to say which values are expected. |

The administrator can also edit a key's description or delete it. Deleting a key removes it from
every envelope that used it, and the application asks for confirmation first. If you are a member
and need a new key, ask your administrator. The steps are in [Label keys](/en/sign/admin/labels/).

## Assign values

A Contributor assigns values in two ways:

- **When creating the envelope**, in the wizard.
- **In the envelope detail**, with **+ Add label**: choose a key and type its value. This works in
  any envelope status, including after sending or completing it.

Each value has between one and <Fact of={LABELS.valueMaxChars} /> characters.

<Aside type="tip" title="Agree on values with your team">
  A label's value is free text. If several people label envelopes of the same project, agree on an
  exact value and record it in the key's description, so that the filter brings them all together.
</Aside>

## Filter the list by label

In the **Envelopes** list, the **Filter by label...** control lets you pick a key and type its value.
You can combine several label filters: the list shows the envelopes that match all of them. Label
filters also combine with the status, title, date and workspace filters, and can be removed one by
one with **Remove filter** or all at once with **Clear filters**.

## Permissions

| Action | Who | Permission |
| --- | --- | --- |
| See the keys and filter by label | Every user and API credential in the organization. | `label:read` |
| Assign or change values on an envelope | Contributors and Managers of the envelope's workspace, and administrators. | `label:assign` |
| Create, edit and delete keys | Org Admins. | `label:manage` |

Viewers and Auditors see envelope labels and filter by them. API credentials assign values in the
workspaces where they are Contributors or Managers. See
[Organizations, workspaces and roles](/en/sign/concepts/organizations-workspaces-roles/).
