The quota defines your organization's usage volume: how many envelopes it can create per period,
how much storage it can use, how many users it can have and how many signers each envelope accepts.
Binary Bridges configures it according to the plan agreed with your organization.

**Who:** organization admins; platform admins configure it. **Where:** the **Quota & Usage** panel on
the organization's page. If your menu does not show **Organizations**, ask Binary Bridges support for
your quota details; the app also tells you when a limit is reached.

## Read the usage panel

The **Quota & Usage** panel shows:

- The plan status: **Active**, **Suspended** or **Expired**.
- The period type (**Monthly**, **Yearly** or **Custom**) and, if the plan has an end date, the date
  after **Expires:**.
- The **Envelopes** bar, with the envelopes used and the maximum, and the **Storage** bar, with the
  space used. Each bar changes color when it reaches the warning threshold, by default
  <Fact of={QUOTA.warningThresholdPct} unit="%" />, and turns red at the limit.
- The start and end dates of the current usage period.
- The maximum users and signers per envelope. **Unlimited** means there is no cap.

To create envelopes, the organization needs a quota and an active usage period. If the panel shows
"No quota configured for this organization" or "No active usage period", ask Binary Bridges to set
it up.

## Quota limits

| Limit | What it controls |
| --- | --- |
| Period type | **Monthly**, **Yearly** or **Custom**. At the start of each period, the envelope counter resets to zero. |
| Warning threshold | The percentage from which the bar warns. |
| Maximum envelopes | The envelopes created in the period. |
| Maximum users | The organization's accounts. |
| Maximum storage | The space the stored documents take. |
| Maximum signers per envelope | The signers in one envelope. |
| Expiry date | The day the plan stops being active. |

## When you reach a limit

The app shows a message that says which limit was reached, and the API answers
<Fact of={QUOTA.httpStatusWhenExhausted} />:

| Message | What to do |
| --- | --- |
| "Your organization has reached its envelope limit for this period" | Wait for the next period or ask for a higher limit. |
| "This envelope has more signers than your plan allows" | Reduce the number of signers or ask for a higher limit. |
| "Your organization has run out of document storage" | Ask for a higher limit. |
| "Your organization has reached its user limit" | Ask for a higher limit before inviting more people. |
| "Your organization's plan is suspended" or "has expired" | Contact Binary Bridges to reactivate the plan. |

Envelopes already sent continue normally: signers sign and documents are sealed even when the quota
is exhausted.

## Raise the quota

Binary Bridges sets, updates, renews, suspends and activates each organization's quota according to
the agreed plan. To raise a limit, contact Binary Bridges support.

<Aside type="tip" title="Ask for the increase early">
  When the envelope bar approaches the warning threshold, ask for the increase so your users can keep
  sending without interruption.
</Aside>
