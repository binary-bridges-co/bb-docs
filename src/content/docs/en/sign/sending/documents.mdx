The Documents step of the "Create Envelope" wizard attaches the files to be signed. Documents are
uploaded right away, before the envelope exists, and are frozen when you send. This page covers the
step, the limits and what happens to a file you upload and never send.

## Upload

The "Upload Documents" screen says: "Attach the PDF document(s) to be signed." Press "Click to
upload PDF" and choose one or more files. Each file uploads immediately ("Uploading...") and appears
in the list with its name. Until there is at least one, "Next" is disabled and the screen reminds
you: "Upload at least one document to continue."

If a file fails, the application names it along with the reason. The most common reasons:

| Message | What happened | What to do |
|---|---|---|
| "That file is too large." | It exceeds <Fact of={DOCUMENTS.maxUploadMb} unit="MB" />. | Shrink the PDF (compressed images, fewer pages) and upload it again. |
| "Your organization has run out of document storage." | Your organization hit its ceiling of unattached documents, or the plan's storage quota. | Send the envelopes you have half done, or wait for unattached files to be cleaned up; if it persists, ask your administrator to raise the limit. |
| The file is not a PDF | Only <code>{DOCUMENTS.contentType.value}</code> is accepted. | Convert the document to PDF and upload it. |

## PDF only

bb-sign signs PDF only. A text document, an image or a spreadsheet must be converted first. The PDF
needs no form fields or special preparation: each signer's seal is placed on the document when the
envelope completes.

## Limits

| What | Value |
|---|---|
| Maximum size per file | <Fact of={DOCUMENTS.maxUploadMb} unit="MB" /> |
| Unattached documents per organization | <Fact of={DOCUMENTS.maxUnassignedPerOrgMb} unit="MB" /> |
| How long an unattached document is kept | <Fact of={DOCUMENTS.unassignedRetentionHours} unit="h" /> |

There is no limit on the number of documents per envelope, but each one counts towards your
organization's storage quota when the envelope is created. See [Quotas](/en/sign/concepts/quotas/).

## Before sending

The wizard has no button to remove a file already uploaded. If you uploaded the wrong document:

- If the envelope has not been created yet, use "Start over" in the draft notice. The wizard
  empties and the file stays unattached until the system deletes it (see the next section).
- If the envelope was created but not sent, its documents cannot be changed from the application.
  [Cancel it](/en/sign/sending/cancel/) and create a new one.

When you send, the documents are frozen. An envelope with no documents cannot be sent.

## Documents uploaded without an envelope

Because the envelope does not exist until you press "Send Envelope", every PDF you upload lives for
a while without an envelope. Those files cost no quota. A daily process deletes the ones that have
spent more than <Fact of={DOCUMENTS.unassignedRetentionHours} unit="h" /> without being attached
to any envelope.

If you return to the wizard after that window, the draft is restored without the files and the
application tells you: "Your uploaded documents expired and were removed. Everything else was kept
— please upload them again." Title, signers and options are still there; only the Documents step
needs repeating.

## The signer marker

If you want each signer's seal to land in a specific place in the PDF, write in the document the
text `{{signerN}}`, where N is the signer's order number: `{{signer1}}` for the first,
`{{signer2}}` for the second. When the envelope completes, the seal is placed over that text.
Without a marker, the seals stack in the bottom right corner of the last page.

What the seal looks like and what it contains is in [Documents](/en/sign/concepts/documents/) and
[Electronic signature and seal](/en/sign/concepts/signature-and-seal/).
