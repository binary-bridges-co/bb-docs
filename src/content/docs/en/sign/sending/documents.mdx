In the **Documents** step of the **Create Envelope** wizard you attach the files to be signed.
Each document uploads right away and is fixed when you send the envelope, so every signer signs
exactly the same content.

## Each document's fingerprint

When each file is uploaded, bb-sign computes and records its SHA-256 fingerprint. The fingerprint
appears on the envelope page ("SHA-256 of the original:"), the signer sees it next to each document
while reviewing them and the evidence certificate includes it. Each signature is bound to the
fingerprints of the documents the signer saw: if a document changed, the signature would not be
recorded.

## Upload the documents

The **Upload Documents** screen says: "Attach the PDF document(s) to be signed." Press **Click to
upload PDF** and choose one or more files. Each file uploads immediately (**Uploading...**) and
appears in the list with its name. The **Next** button becomes available as soon as there is at
least one document.

Review the documents before you continue; to change them, use **Start over**.

If a file cannot be uploaded, the application shows its name and the reason:

| Message | Cause | What to do |
|---|---|---|
| "That file is too large." | The file exceeds <Fact of={DOCUMENTS.maxUploadMb} unit="MB" />. | Reduce the PDF's size (compressed images, fewer pages) and upload it again. |
| "Your organization has run out of document storage." | Your organization reached its limit of unattached documents or the plan's storage quota. | Send your pending envelopes or wait for unattached documents to be released. If it continues, ask your administrator to raise the limit. |
| The file is not a PDF | The accepted format is <code>{DOCUMENTS.contentType.value}</code>. | Convert the document to PDF and upload it. |

When you send the envelope, this message can also appear:

| Message | What happened | What to do |
|---|---|---|
| "One of the documents does not have its fingerprint recorded yet, so the envelope cannot be sent. Wait a few minutes or upload it again." | A document does not have its SHA-256 fingerprint recorded yet, and bb-sign does not send an envelope without it. The envelope stays in **Draft**. | Wait a few minutes and press **Send Envelope** again. If the message continues, cancel the draft and create the envelope again with the document uploaded anew. |

## Prepare the PDF

bb-sign signs PDF documents. Convert any text document, image or spreadsheet to PDF first. The PDF
needs no form fields or special preparation: each signer's seal is placed on the document when the
envelope completes.

An envelope can include as many documents as you need. Each one counts towards your
organization's storage quota when the envelope is created. See [Quotas](/en/sign/concepts/quotas/).

## Correct an envelope created but not sent

If the envelope has been created but not sent yet and you need to change its documents,
[cancel it](/en/sign/sending/cancel/) and create a new one. When you send, the documents are fixed.

## Documents uploaded without an envelope

The envelope is created when you press **Send Envelope**; until then, uploaded PDFs are kept
without an envelope and use no quota. Every day, bb-sign deletes those that have gone more than
<Fact of={DOCUMENTS.unassignedRetentionHours} unit="h" /> without being attached to an envelope.

If you return to the wizard after that period, the draft keeps the title, signers and options, and
the application says: "Your uploaded documents expired and were removed. Everything else was kept
— please upload them again." Upload the documents again and continue.

## Place the seal with the signer marker

To have each signer's seal appear in a specific place in the PDF, write the text `{{signerN}}` in
the document, where N is the signer's place in the list on the **Signers** step, counting from the
top: `{{signer1}}` for the first card, `{{signer2}}` for the second. With signing at once the cards
show no number, but the order still counts. When the envelope completes, the seal is placed over that text. Without a marker, the
seals are placed in the bottom right corner of the last page.

The seal's appearance and contents are described in [Documents](/en/sign/concepts/documents/) and
[Electronic signature and seal](/en/sign/concepts/signature-and-seal/).
