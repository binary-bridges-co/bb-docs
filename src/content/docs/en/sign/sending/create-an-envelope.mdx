The **Envelope Details** step of the **Create Envelope** wizard defines how the envelope behaves
from start to finish: who can see it, how each signer is identified and how long it can be signed.
This page describes each field in the order it appears. For the full walkthrough, see
[Your first envelope](/en/sign/getting-started/first-envelope/).

## Choose the workspace

The **Workspace** selector lists the workspaces where you can create envelopes. **General
(everyone)** is selected by default. As the help text says: "Only people with access to this
workspace will see the envelope."

Choose the workspace first: it determines who can view, download and cancel the envelope, and it
stays the same for the envelope's whole life. See
[Organizations, workspaces and roles](/en/sign/concepts/organizations-workspaces-roles/).

## Give the envelope a title

The **Title** field is required. It is the envelope's name in the Envelopes list, on the detail page and
in the subject of the emails to the signer, for example `You have a document to sign: {title}`.
Use a title the signer will recognize right away.

## Add labels

The **Labels** block appears when an administrator has defined label keys for your organization.
Choose a key in **Add label...**, type the value and press **Add**. Each value holds up to
<Fact of={LABELS.valueMaxChars} unit="characters" />.

Labels let you filter the Envelopes list, and you can change them later from the envelope page,
even after sending. See [Labels](/en/sign/concepts/labels/).

## Message to signers

**Message to signers** is an optional field for saving a note with the envelope. If signers need
instructions, include them in the document itself.

## Verify identity with OTP

**Require OTP verification for signers** is checked by default. With this option, each signer
confirms they control their email before signing: bb-sign sends them by <Fact of={OTP.channel} />
a code of <Fact of={OTP.digits} unit="digits" /> that is valid for
<Fact of={OTP.validitySeconds} unit="s" />, with <Fact of={OTP.maxAttempts} unit="attempts" />
available. The signer can request a new code after <Fact of={OTP.resendCooldownSeconds} unit="s" />.
Once verified, they have <Fact of={OTP.verifiedValidityMinutes} unit="min" /> to submit their
signature.

Without this option, the link in the email is the signer's only identification. Keep it checked
whenever you need evidence that the signer controls their email.

## Set the signing order

**Signing order** offers two options:

| Option | Behavior |
|---|---|
| **Everyone signs at once** | "Everyone is emailed at once and can sign in any order." |
| **Signers sign in order** | "Signers are emailed one at a time, in the order you set on the signers step." |

With the second option, the **Signers** step shows the **Order** field. See
[Signers and order](/en/sign/sending/signers-and-order/).

## Set the link expiry

**Link expiry (hours)** sets how long each signer's signing link is valid, in whole hours. The
default is <Fact of={ENVELOPE.linkTtlHoursDefault} unit="h" />. The clock starts when the link is
generated: at send, if everyone signs at once; when each signer's turn comes, if they sign in
order.

Choose a period that matches how long your signers usually need. If a link expires, the signer
sees the **Link Unavailable** page; in that case,
[cancel the envelope](/en/sign/sending/cancel/) and create a new one.

## Set an expiration date

**Expires at (optional)** sets a date and time limit for the whole envelope. As the help text
says: "Leave empty for no expiration." If you set it, it must be in the future.

Every <Fact of={ENVELOPE.expirySweepMinutes} unit="min" />, bb-sign checks envelopes in **Sent** or
**In Progress** whose date has passed and marks them **Expired**. Their signers receive the email
`Signing request expired: {title}` and the links close. The **Expired** status is final.

<Aside type="note" title="Link expiry and envelope expiration">
  Link expiry applies to each signer separately and does not change the envelope status.
  Expiration closes the whole envelope. An envelope with no expiration date whose links have
  expired stays **Sent** until you cancel it.
</Aside>
