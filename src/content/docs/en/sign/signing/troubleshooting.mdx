This table lists the messages you can see while signing, downloading your copy and verifying it, and
the action that resolves each case. When the envelope needs a change, the person who sent you the
document can review it, correct it or send you a new one.

## Messages and solutions

| What you see | What happened | What to do |
|---|---|---|
| **Link Unavailable** and below it "This signing link has expired" | The link expired. It is valid for <Fact of={ENVELOPE.linkTtlHoursDefault} unit="hours" /> by default, or for the period set by the person who sent the document. | Ask the person who sent you the document to review the envelope or send you a new one. |
| **Link Unavailable** and below it "This signing link has already been used" | Someone already signed with this link. | If it was not you, tell the person who sent you the document right away. |
| **Link Unavailable** and below it "Envelope is not open for signing" or "This envelope has expired" | The envelope was cancelled, expired or is already complete. | Ask the person who sent you the document whether you should receive a new one. |
| **Link Unavailable** and below it "Failed to load signing page." | The page could not connect to the service, or the link is incomplete. | Reload the page. If the message persists, open the link from the original email. |
| **Waiting for Previous Signers** | The envelope has a signing order and the people before you have not signed yet. | The page refreshes automatically; you can also press **Check Again**. When it is your turn, you receive `It's your turn to sign: {title}`. |
| **Already Signed** | You have already signed this document with this link. | Nothing else is needed. When everyone has signed, you receive `Signing complete: {title}`. |
| "That code is not valid. Please check it and try again." | The code does not match or has expired. Each code allows <Fact of={OTP.maxAttempts} unit="attempts" />. | Copy the code from the latest email. If it does not work, request another with **Resend code**. |
| "That code can no longer be used. You can request a new one shortly." | The code was already used or ran out of attempts, and the wait of <Fact of={OTP.resendCooldownSeconds} unit="s" /> is still running. | When the button shows **Resend code**, request a new one. |
| "Please draw your signature." or "Please type your name." | You pressed **Submit Signature** with the box empty. | Draw or type your signature and submit it again. |
| "Signing failed. Please try again." | The signature could not be recorded. | Press **Submit Signature** again. |
| "Your identity check has expired. Please request a new code." | More than <Fact of={OTP.verifiedValidityMinutes} unit="minutes" /> have passed since verification. | Reload the page and request a new code. |
| "The documents changed while you were reviewing them. Please review them again before signing." | The documents changed after the page loaded them, so bb-sign did not record your signature. | Open each document again, review it and sign again. |
| "Your signed copy is still being prepared. We have emailed you a link — you can download it from there once it is ready." | Sealing is taking longer. | Close the page and download the copy later from the `Signing complete: {title}` email. |
| "Could not download the evidence certificate. Please try again." | The certificate download did not start. | Press **Download Your Evidence Certificate** again. |
| "Your signed copy is archived. Request it and we will email it to you when it is available." | Your copy is in archive storage. | Press **Request my copy**. The restore usually takes a few hours; then you receive an email with the link. |
| "Your signed copy is being restored. Request it and we will email it to you when it is available." | Someone else has already asked for the copy and the restore is in progress. | Press **Request my copy** to receive the email too. |
| "We received many requests from this link or your connection. If you already asked, the email will arrive; if not, try again in a few minutes." | The limit of <Fact of={RATE_LIMITS.signerRestorePerLink} /> requests per link or <Fact of={RATE_LIMITS.signerRestorePerIp} /> per connection within <Fact of={RATE_LIMITS.signerRestoreWindowMinutes} unit="minutes" /> was reached. | If you already asked, wait for the email. If not, try again in a few minutes. |
| "We could not request your copy. Try again in a few minutes." | The request did not complete. | Press **Request my copy** again in a few minutes. |
| The restore email says "The restore took longer than expected; you can request it again." or "It could not be restored." | The restore did not finish within <Fact of={RESTORE.timeoutHours} unit="hours" />, or it failed. | Open your link and press **Request my copy** again. If it fails again, contact the person who sent you the document. |
| "Your signed copy is no longer available: its <Fact of={RETENTION_POLICY.retentionDays} />-day retention period has ended." | Your copy's retention period, counted from the envelope's completion, has passed and it was deleted. | Request the document from the person who sent it: from then on, their organization is responsible for keeping it. |
| **Invalid Signature** when scanning the QR code on the seal | If the envelope has already moved to **Archived** (<Fact of={ENVELOPE.archiveAfterDays} unit="days" /> after its creation), the QR check currently fails even though the document is intact. | If the document was signed since bb-sign <Fact of={DOCUMENTS.signedSha256Since} />, check it with **Check a file** at <a href={verifyUrl}>{verifyUrl}</a>. If it was signed earlier, or if that check does not confirm it either, open the PDF in a reader and look at its signature panel. If in doubt, ask the person who sent you the document. See [Verify a signed document](/en/sign/signing/verify-a-document/). |

## If you do not wish to sign

Close the page and contact the person who sent you the document, who can cancel the envelope. If
you do not sign, the link expires at the end of its validity period.

## If you need a new link

Ask the person who sent you the document to review the envelope. They can confirm your email
address and, if the envelope is still open, the reminders will reach you with the same link. If the
envelope has expired, they can send you a new one.
