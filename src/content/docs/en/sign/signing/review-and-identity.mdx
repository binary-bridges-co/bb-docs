Before signing, you review each document and, if the envelope requires it, confirm your identity
with a code sent to your email. The indicator at the top shows which step you are on: **Review**,
**Verify** (when it applies) and **Sign**.

## Confirm your details

The screen shows **Signing as** with your name and email. These are the details that will appear
on the document's seal. If they are not yours, do not continue and contact the person who sent you
the document so they can correct them.

## Review each document

Under **Documents to Review**, press **View** to open each PDF on the same page and **Hide** to
close it. Once you have opened every document, press **I have reviewed the document**. If you try
to continue earlier, you see the message "Open every document before you continue."

If your browser cannot display the PDF, you see "Your browser cannot display this PDF inline." Use
**Download the document** to open it; that download also counts as a review.

## Each document's fingerprint

Next to each document you see its fingerprint, "Fingerprint (SHA-256):", with the first and last
<Fact of={SIGNER.fingerprintShownChars} /> characters; hover over it to see it in full. It is the fingerprint bb-sign recorded when the document
was uploaded, and your signature will be bound to it. You can compare it later with the one in your
evidence certificate.

If the documents change while you are reviewing them, bb-sign does not record the signature and the
page shows:

| Message | What happened | What to do |
|---|---|---|
| "The documents changed while you were reviewing them. Please review them again before signing." | The recorded documents are no longer the ones the page showed you, so your signature was not recorded. The page returns to the **Review** step with the current documents. | Open each document again, review it and sign again. |

## Verify your identity

When the envelope requires verification, pressing **I have reviewed the document** makes bb-sign
email you a code and opens the **Verify Your Identity** screen, which shows how long the code
remains valid.

- The code has <Fact of={OTP.digits} unit="digits" /> and is valid for <Fact of={OTP.validityMinutes} unit="minutes" />.
- Each code allows <Fact of={OTP.maxAttempts} unit="attempts" />.
- You can request another with **Resend code** <Fact of={OTP.resendCooldownSeconds} unit="s" />
  after the last one was sent; until then, the button shows a countdown.
- The page always accepts the most recent code.
- Each code works only for you: a code sent to another signer is not valid on your link.

Enter the code and press **Verify & Continue**.

## Verification messages

| Message | What happened | What to do |
|---|---|---|
| "A code was already sent to your email." | You requested another code before the wait ended, and the previous one is still valid. | Use the code you already received. |
| "A new code is on its way." | A new code was sent. | Use the new code. |
| "That code can no longer be used. You can request a new one shortly." | The code was already used or ran out of attempts, and the wait is still running. | When the button shows **Resend code**, request another. |
| "That code is not valid. Please check it and try again." | The code does not match, has expired or is not the most recent one. Each error counts as an attempt. | Copy the code from the latest email. If you ran out of attempts, request a new one. |
| "Could not verify the code. Please try again." | The verification did not complete. | Press **Verify & Continue** again. |
| "Failed to send OTP. Please try again." | The email could not be sent. | Press **I have reviewed the document** again. |

## After verifying

Once the code is verified, you have <Fact of={OTP.verifiedValidityMinutes} unit="minutes" /> to
sign. The verification is recorded (the method, the channel, the masked destination and the time the
code was accepted) and appears in the envelope's evidence certificate. If that time runs out, reload the page, open the documents again and request a new code.
Continue with [Sign and download](/en/sign/signing/sign-and-download/).
